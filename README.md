## 📌 Descripción

Aplicación web desarrollada para el **estudiante del Complejo Educativo Thomas Jefferson** (Sonsonate) que permite a padres de familia y encargados generar el **Formato de Solicitud de Permisos por Inasistencia** de manera digital.

El sistema genera un PDF idéntico al formato oficial de la institución, listo para imprimir o enviar.

---

## ✨ Características

- Interfaz moderna y responsive
- Formulario intuitivo con validaciones
- Generación automática de explicación formal
- Calendario para dias escolares
- Validación de teléfono +503
- Vista previa del documento antes de descargar
- PDF con el formato oficial de la institución
- Logo institucional incluido
- Diseño con los colores oficiales del colegio

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3** (con animaciones y efectos modernos)
- **JavaScript**
- **jsPDF** → Generación de PDF
- **html2canvas** → Soporte para vista previa

---

## 🚀 Cómo usar

1. Completa todos los campos del formulario.
2. (Opcional) Escribe un motivo corto y presiona **“Crear Explicación Formal”**.
3. Haz clic en **“Generar Documento PDF”**.
4. Revisa la vista previa.
5. Descarga el PDF listo para usar.
